# assets

This project intentionally uses emoji and CSS gradients as visual placeholders
for product/service/event images, so it runs instantly offline with zero
external image dependencies and no broken-image states.

Drop any real photos you want to use here (e.g. `assets/products/`) and swap
the `<div class="card-media">{icon}</div>` markup in `js/marketplace.js` for
an `<img>` tag pointing at your file.
